## ID Format Notes

- **Reference doc system screen IDs**: 32-character hexadecimal strings (e.g., `fbe4384a12264d05beabb17d381cb56a`)
- **Stitch project-relative IDs**: 32-character hexadecimal strings (e.g., `16ba66e852cf4f05bdfd0def84d89899`) — these are the IDs visible in the Stitch canvas URL `projects/9850514973960087780/screens/16ba66e852cf4f05bdfd0def84d89899`
- **Live Canvas Item IDs** (from the new reference doc `Pencil'd — Accurate Live Canvas ID & Architecture Map`): Different 32-char hex strings (e.g., `19890c6eccda4ab4af40606b516bfd42` for Home Empty State) — these are the currently active IDs in the live Stitch canvas
- **Mapping**: Stitch project IDs directly correspond to the reference doc `stitch-screens.md` system screen IDs. The Live Canvas Item IDs are a separate numbering system that reflects the live canvas state.
