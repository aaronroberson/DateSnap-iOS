# Pencil’d App Store creative package

Status: implementation-ready creative brief. App Store Connect publication and live
device captures remain external release steps.

## Default six-screenshot set

Capture the real production UI on iPhone 6.7-inch and iPad 13-inch after the runtime
smoke pass. Keep the same dark Pencil’d surface, use the actual localized StoreKit
prices only where a paywall is shown, and do not add fabricated counts or events.

1. **Stop retyping dates.** Home source cards beside a populated Review screen.
   Subline: `Turn a flyer or screenshot into a calendar event.`
2. **Turn a full schedule into separate events.** A real schedule capture followed by
   the populated Batch Review list. Subline: `Review every shift before saving.`
3. **Your review stays in your hands.** Event Review with evidence, confidence, and
   editable fields visible. Subline: `Nothing reaches Calendar until you confirm.`
4. **Save to Calendar and Reminders.** The successful save state and destination
   controls. Subline: `Choose the calendar, alerts, and reminder list.`
5. **Find event screenshots automatically.** Home’s Plus screenshot surface with
   the real likely-event state. Subline: `On-device triage highlights what to scan.`
6. **Private and on-device.** The privacy panel and a populated event detail screen.
   Subline: `Your photos and documents stay on your iPhone.`

### Capture rules

- Use real app state produced by the local scan/import path; never use fixture text in
  release screenshots.
- Capture Dynamic Type Large or the default size only after checking the 44-point
  target and VoiceOver labels.
- Keep the first frame problem-led, the second frame schedule-led, and the third
  frame accuracy-led. Do not imply Premium-only schedule import is free.
- Export the six-frame set per required App Store Connect device size and record the
  simulator/device identifier with the release evidence.

## Work-schedules Custom Product Page

Audience: people who receive shift schedules as screenshots or flyers.

- **Page purpose:** convert schedule-heavy users with the schedule extraction flow.
- **Promotional text:** `Turn work schedules into calendar events.`
- **Headline:** `Every shift, ready for review.`
- **Supporting copy:** `Import a schedule, split each dated shift into its own event,
  then review the details before saving to Apple Calendar.`
- **Screenshot order:** frame 2, frame 3, frame 4, then frame 6. Mark schedule
  splitting and any Premium-only capability clearly in the creative.
- **Keyword candidate:** `schedule,shift,work,roster,calendar,planner,flyer`
  (final 100-character field decision remains an App Store Connect metadata gate).

The page should be created only after the default listing is Ready for Distribution;
the page’s impressions, downloads, conversion, retention, and proceeds are measured
in App Store Connect rather than through an in-app analytics SDK.
